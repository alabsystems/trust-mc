# Crates documentation

trust-mc currently ships with a `kani` crate that provides APIs to allow users to
write and configure their harnesses.
These APIs are tightly coupled with each trust-mc version, so they are not
published yet at <https://crates.io>.

You can find their latest documentation here:
  - [kani](https://model-checking.github.io/kani/crates/doc/kani) (upstream Kani docs; trust-mc-specific
  behavior may differ): This crate provides APIs to write trust-mc harnesses.
